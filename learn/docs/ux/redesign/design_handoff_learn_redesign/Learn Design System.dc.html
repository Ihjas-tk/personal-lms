The component system

Tokens, type, spacing, the reduced state vocabulary, plain-language naming, the three states the screens do not show, and what maps onto which file. Everything here is CSS custom properties and plain React — no library, no Tailwind.

1 · Colour

Nine token families, same names as today's tokens.css where they already existed. Violet replaces the slate accent; amber stays the only warning; a red tint is added for destructive confirmation only, never for learning state. No colour carries meaning on its own — every state also carries text.

2 · Type

Three families with one job each. Playfair Display carries the human voice — your own sentences, the prompts you have to answer. Plus Jakarta Sans is every label and control. JetBrains Mono is anything countable: hours, dates, paths, timestamps, ids, scores. The old app had one 15px system font doing all three.

6 · The three states the screens do not show

6.1 Tidy — reviewing the copy-edit

AI never writes to a file. The tidied text streams into a shadow buffer and arrives as a diff you take chunk by chunk. Left is yours and read-only; right is editable.

Tidy · review each change

Six words added, nothing else. Numbers, code, maths and links are checked before you see this.

Refused — the tidy changed something it is not allowed to change

Numbers differ: 1/sqrt(d_k) became 1/d_k. Your note was not touched and there is no diff to review. The refusal is logged.

6.2 The note changed underneath you

Conflicts are refused, never merged. Two exits, both named for what they destroy.

This note changed on disk since you opened it, so the save was refused

Both versions still exist. Your edits are held in the editor until you choose.

6.3 AI is unavailable

Blocked, never hidden. The entries stay where they are, disabled, with the reason stated once in plain words rather than as a tooltip you have to hunt for.

All three read as a state of the world, not a failure of yours, and none of them removes a control from the page.
